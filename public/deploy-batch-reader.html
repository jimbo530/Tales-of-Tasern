BatchReader Contract

Batch reads for all D20 NFTs + LP pairs. Deploy on both Base and Polygon.

22 Base NFTs x 12 LPs = 264 reads/call | 182 Polygon NFTs x 90 LPs = chunked ~20 NFTs/call

Select a chain and deploy

Contract Functions

batchPairInfo(pairs[]) - returns token0, token1, totalSupply, reserve0, reserve1 for all LP pairs

batchLpBalances(nfts[], pairs[]) - returns flat array of LP balances for every NFT x pair combo

batchNftBalances(nfts[], account, tokenId) - returns ERC1155 balanceOf for ownership checks

batchAll(nfts[], pairs[]) - pair info + LP balances in one call (use for Base; chunk Polygon by ~20 NFTs)
