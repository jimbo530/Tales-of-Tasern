How Reactor Burns Work

  • Every swap through an MfT reactor pool generates 1% fees
  • The token side of fees is sent to this burn address — permanently removing it from circulation
  • The other side deepens liquidity, making future trades more efficient
  • Multiple reactors (MfT, EARTH, game tokens) all feed burns here
  • Burns compound every 2.4 hours via autonomous keepers
  • This address has no private key — tokens sent here can never be moved
  • Everything on this page is read directly from Base — verify any number on Basescan
